# FoodDeliverySystem

A multi-platform Food Delivery System application.

## Project Structure

- `backend/`: ASP.NET Core 8.0 Web API service.
- `frontend/`: React + TypeScript Web application (powered by Vite).
- `mobile/`: Flutter mobile application for iOS & Android.

## Getting Started

### Backend (.NET 8 Web API)
```bash
cd backend
dotnet run
```

### Frontend (React + TypeScript)
```bash
cd frontend
npm install
npm run dev
```

### Mobile App (Flutter)
```bash
cd mobile
flutter run
```
